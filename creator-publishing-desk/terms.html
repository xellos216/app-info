적용과 동의

Creator-Publishing-Desk는 xellos216이 관리하는 채널의 제작물을 전달하기 위한 개인용 개발 도구입니다. 도구를 사용하기 전에 이 약관과 개인정보처리방침을 읽고 동의해야 합니다. 현재 별도의 앱 내 약관 동의 화면·버전 기록 기능은 없습니다.

이 앱은 YouTube API Services를 사용합니다. 이 앱을 사용하는 이용자는 YouTube 서비스 약관에도 동의하고 그 약관의 적용을 받습니다. Google의 데이터 처리는 Google 개인정보처리방침을 참고하세요.

권한과 작업 승인

이용자는 자신이 관리 권한을 가진 채널과 적법하게 사용할 수 있는 제작물만 지정해야 합니다. 저작권, 시청자 구분, 합성·변경 콘텐츠 표시, 협찬·유료 프로모션 여부 및 제목·설명은 실제 내용에 맞게 결정해야 합니다.

Google 권한 동의는 모든 동작에 대한 포괄적인 실행 지시가 아닙니다. 업로드 대상·설정과 후속 변경은 사용자가 명시적으로 결정합니다. 영상 완성이나 비공개 업로드 성공만으로 공개·예약·삭제·권한 철회를 수행하지 않습니다.

제공 기능과 제한

로컬 실행은 계획·파일 검증, 채널 확인, 비공개 업로드, 자막·썸네일 적용과 상태 확인을 제공합니다. 처리 대기 후 같은 영상에 후속 작업을 이어가는 동작을 실제로 확인했습니다. 공개·예약·연결 해제 기능과 오류 복구 경로의 상당 부분은 모의 응답 검증에 한정됩니다. 자세한 확인 범위는 앱 소개에 표시합니다.

네트워크 또는 API 오류로 결과가 불확실하면 작업이 멈출 수 있습니다. 임의로 상태를 지우거나 같은 영상을 다시 올리지 말고 기존 기록과 원격 결과를 확인해야 합니다. 무중단 운영, 정확히 한 번의 업로드, 플랫폼의 업로드 수락 또는 심사 승인을 보장하지 않습니다.

보관과 연결 해제

사용자는 로컬 원본과 인증 정보를 보호해야 합니다. 연결 해제 기능의 관리 대상 및 제외 자료는 권한 철회·삭제 안내를 따릅니다. 로컬 데이터 삭제와 YouTube 영상 삭제는 다른 작업입니다. 자동 보관기간 관리와 외부 결과 기록 정리가 구현되었다고 약속하지 않습니다.

독립성 및 심사 상태

이 앱은 Google 또는 YouTube가 운영·후원하는 공식 앱이 아닙니다. OAuth 프로덕션 상태, OAuth 검증, YouTube API 준수 심사는 별개이며, 이 페이지 게시나 비공개 업로드 성공이 그 승인을 뜻하지 않습니다. API의 비공개 제한을 우회하지 않으며 공개 기능 사용 가능 여부는 플랫폼 정책과 심사 결과에 따릅니다.

변경·문의

도구는 개인용 개발 단계로, 기능과 문서가 변경될 수 있습니다. 중요한 데이터 처리 변경은 이 공개 문서와 갱신일에 반영합니다. 이 약관은 적용되는 법률상 권리를 제한하려는 목적이 아닙니다. 이용·개인정보 관련 문의는 GitHub 문의 창구로 보내되 비밀이나 비공개 자료를 게시하지 마세요.
