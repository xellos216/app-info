Creator-Publishing-Desk

개인 제작자를 위한 로컬 YouTube 게시 도구

용도와 운영자

Creator-Publishing-Desk는 xellos216이 자신이 관리하는 채널의 영상 제작물을 YouTube에 전달하기 위해 사용하는 개인용 명령줄 도구입니다. 불특정 이용자를 모집하는 호스팅 서비스가 아닙니다.

이 사이트는 앱 안내 문서만 제공합니다. 여기에서 로그인하거나 영상을 업로드하지 않습니다. 실제 작업은 운영자의 컴퓨터에서 실행되며, 로그인·권한 동의는 Google의 브라우저 화면에서 진행합니다.

어떻게 사용하는가

  1. 전달할 영상·자막·썸네일과 대상 채널, 제목·설명·시청자 설정 등을 검토합니다.
  2. 운영자가 작업을 승인하고 Google 계정에서 대상 채널을 선택해 동의합니다. 도구가 실제 채널 ID를 확인합니다.
  3. 비공개로 업로드하고 처리 상태와 요청한 자막·썸네일, 설정을 확인합니다. 결과가 불확실하면 새 영상으로 대체하지 않고 확인을 위해 멈춥니다.
  4. 공개·예약 또는 연결 해제는 각각 별도 요청으로만 실행하도록 구현되어 있습니다. 비공개 업로드만으로 공개되지 않습니다.

이용 전에 개인정보처리방침과 이용약관을 읽어 주세요. 데이터 관리 기능을 추가한 CLI는 인증·API 사용 전에 정책 원문과 버전을 표시하고 사용자의 명시적 동의를 로컬에 기록합니다. 문서가 바뀌면 다시 동의해야 합니다. 설치·이전 업로드 승인·Google OAuth 동의가 이 정책 동의를 대신하지 않습니다. 도움말·오프라인 검사·삭제 요청·연결 해제는 새 동의 없이 사용할 수 있습니다.

현재 배포와 확인된 범위 · 2026-10-12

현재 운영 환경은 TaleMouse local port이며, 설치본의 개인정보처리방침·이용약관 개정일은 2026-10-08입니다. 이 사이트의 공개 정책 문서는 2026-09-20 upstream 버전입니다. 두 문서를 동일한 배포본으로 간주하지 않으며, 실제 실행 시에는 설치본이 표시하는 정책 원문과 버전을 확인합니다.

운영 기록으로 확인
2026-10-11에 현재 설치본 정책 버전에 대한 운영자의 명시적 동의가 기록되었습니다. 2026-10-12에 기록된 기존 인증 확인과 로컬 데이터 점검 결과도 확인했습니다. 실제 게시 작업에서 영상당 영어 포함 수동 자막 14개, 번역 제목·설명 13개와 Studio를 통한 추가 더빙 3개의 등록을 확인했습니다. 영어 원음은 영상에 포함됩니다.
업로드와 복구
승인된 파일·대상·언어를 계획에 고정하고, 비공개 업로드 후 자막과 문구를 적용합니다. 할당량 거부로 중단된 작업은 기존 영상과 등록된 자막을 유지한 채 나머지를 재개했습니다. 등록 상태 확인과 영상 전체의 재생·청취·번역 품질 검수는 별도로 수행합니다.
검증의 한계
기록된 동의와 인증 확인만으로 실제 권한 철회, 외부 사본·백업의 완전 삭제, 다중 채널 운영 또는 Google·YouTube 심사 통과를 입증하지는 않습니다. 권한 철회·삭제·일부 복구 경로의 오프라인 모의 검증과 실제 서비스 검증을 구분합니다.

검토자는 공개 문서에서 앱의 용도와 정책을 확인할 수 있습니다. 실행 가능한 공개 데모나 호스팅 로그인은 없으며, 로컬 작업 흐름은 별도로 제공하는 비밀정보 제외 계획·명령 화면·기존 실행 결과로 설명합니다.

데이터 관리와 운영자 절차

관리 대상과 실제 저장·갱신 시각을 점검하고, 갱신·삭제는 먼저 대상과 이유를 미리 보여줍니다. 실제 변경에는 명시적 실행 선택이 필요합니다. 원본 제작물과 승인 자료, API 데이터, 인증 정보와 업로드 복구 상태를 구분합니다. 오래된 기록의 알 수 없는 시각은 임의로 채우지 않습니다.

상시 서버나 자동 타이머는 없습니다. 운영자는 보관 중 매일 로컬 점검을 하고, 별도로 승인된 권한·채널 점검과 적용 기한 안의 갱신·삭제를 수행해야 합니다. 승인된 외부 파일만 목록에 등록하며, 보고서·화면 사본·백업 정리는 수동 절차입니다. 등록하지 않은 사본까지 찾아 지웠다고 보장하지 않습니다.

공개 upstream 정책 원문은 개인정보처리방침과 이용약관에서 읽고 내려받을 수 있습니다. 현재 로컬 포트는 설치본 정책을 표시하며, 해당 원문과 policy_version을 확인하고 실제로 동의한 때에만 기록합니다.

접근 권한과 사용자 통제

앱은 YouTube API Services를 사용합니다. 자막을 포함하는 작업은 youtube.force-ssl 권한을 요청합니다. 이 권한은 요청한 한 영상보다 넓은 YouTube 관리 범위를 허용하므로, 실제 작업은 운영자가 승인한 대상과 동작으로 제한합니다. 계정 비밀번호를 앱에 입력하거나 저장하지 않습니다.

파일과 인증 정보는 이 공개 사이트로 전송하지 않습니다. 데이터 종류, 저장 및 삭제 범위는 개인정보처리방침에서 확인할 수 있습니다.

Google·YouTube와의 관계

Google 또는 YouTube의 공식 앱이 아니며, 검증이나 준수 심사를 승인받았다고 주장하지 않습니다. Google OAuth의 프로덕션 전환, OAuth 브랜드·권한 검증, YouTube API 준수 심사는 서로 다릅니다. 프로덕션 전환만으로 API 업로드 영상의 비공개 제한이 해제되지는 않습니다.

공개 업로드 관련 정책과 제한은 YouTube 공식 업로드 문서를 따릅니다.
