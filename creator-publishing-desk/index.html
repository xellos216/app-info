Creator-Publishing-Desk

개인 제작자를 위한 로컬 YouTube 게시 도구

용도와 운영자

Creator-Publishing-Desk는 xellos216이 자신이 관리하는 채널의 영상 제작물을 YouTube에 전달하기 위해 사용하는 개인용 명령줄 도구입니다. 불특정 이용자를 모집하는 호스팅 서비스가 아닙니다.

이 사이트는 앱 안내 문서만 제공합니다. 여기에서 로그인하거나 영상을 업로드하지 않습니다. 실제 작업은 운영자의 컴퓨터에서 실행되며, 로그인·권한 동의는 Google의 브라우저 화면에서 진행합니다.

어떻게 사용하는가

  1. 전달할 영상·자막·썸네일과 대상 채널, 제목·설명·시청자 설정 등을 검토합니다.
  2. 운영자가 작업을 승인하고 Google 계정에서 대상 채널을 선택해 동의합니다. 도구가 실제 채널 ID를 확인합니다.
  3. 비공개로 업로드하고 처리 상태와 요청한 자막·썸네일, 설정을 확인합니다. 결과가 불확실하면 새 영상으로 대체하지 않고 확인을 위해 멈춥니다.
  4. 공개·예약 또는 연결 해제는 각각 별도 요청으로만 실행하도록 구현되어 있습니다. 비공개 업로드만으로 공개되지 않습니다.

이용 전에 개인정보처리방침과 이용약관을 읽어 주세요. 현재 CLI에는 별도의 약관 동의 화면이나 동의 버전 기록 기능이 없습니다.

현재 확인된 범위

실제 테스트 성공
사용자 로그인·권한 동의, 채널 확인, 영상 1개의 비공개 업로드와 처리 완료, 한국어 자막·썸네일 적용, 같은 영상의 제목·유료 프로모션 설정 변경과 재조회.
모의 응답으로 검증
전송 중단·불확실한 응답 복구, 토큰 갱신, 공개·예약, 권한 철회와 관리 대상 로컬 데이터 삭제. 이러한 실패·변경 상황을 실제 Google 서비스에서 모두 시험한 것은 아닙니다.
아직 확인하지 않은 사항
다중 채널 운영, 전체 재생·자막 가독성 평가, 현재 앱 이름이 표시된 권한 동의 화면 증빙, 공개 업로드 허용 여부와 각종 심사 승인.

테스트 도구는 개발 중이며 정식 배포 완료를 뜻하지 않습니다. 제목·유료 프로모션의 기존 영상 수정 테스트에는 별도의 제한된 보조 실행 절차를 사용했습니다.

접근 권한과 사용자 통제

앱은 YouTube API Services를 사용합니다. 자막을 포함하는 작업은 youtube.force-ssl 권한을 요청합니다. 이 권한은 요청한 한 영상보다 넓은 YouTube 관리 범위를 허용하므로, 실제 작업은 운영자가 승인한 대상과 동작으로 제한합니다. 계정 비밀번호를 앱에 입력하거나 저장하지 않습니다.

파일과 인증 정보는 이 공개 사이트로 전송하지 않습니다. 데이터 종류, 저장 및 삭제 범위는 개인정보처리방침에서 확인할 수 있습니다.

Google·YouTube와의 관계

Google 또는 YouTube의 공식 앱이 아니며, 검증이나 준수 심사를 승인받았다고 주장하지 않습니다. Google OAuth의 프로덕션 전환, OAuth 브랜드·권한 검증, YouTube API 준수 심사는 서로 다릅니다. 프로덕션 전환만으로 API 업로드 영상의 비공개 제한이 해제되지는 않습니다.

공개 업로드 관련 정책과 제한은 YouTube 공식 업로드 문서를 따릅니다.
