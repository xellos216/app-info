데이터 접근·저장·보관과 삭제

적용 대상과 운영자

이 방침은 xellos216이 운영하는 개인용 Creator-Publishing-Desk와 이 안내 사이트에 적용됩니다. 앱은 YouTube API Services를 사용합니다. Google의 처리는 Google 개인정보처리방침을 따릅니다.

처리하는 데이터와 목적

사용자가 제공한 원본 제작물
선택한 영상·자막·썸네일, 제목·설명·시청자 및 공개 설정입니다. 승인된 업로드와 후속 적용을 위해 읽고 Google/YouTube에 전송합니다. 도구는 원본을 자동 편집하거나 삭제하지 않습니다.
API로 받은 데이터
채널 ID·이름, 업로드 목록의 영상 식별자와 제목, 카테고리, 영상·자막 ID, 처리 상태와 설정, 썸네일 적용 결과 등을 필요한 조회에서 처리합니다. 대상 확인, 중복 방지, 결과 검증에 사용하며 일부 관찰값은 로컬 실행 기록에 남습니다.
인증 정보
데스크톱 OAuth 클라이언트 설정, 액세스·갱신 토큰, 부여된 권한과 만료 정보, 선택한 채널의 연결 정보입니다. Google 로그인 비밀번호는 앱이 수집하지 않습니다. 승인된 API 요청과 토큰 갱신에 사용합니다.
작업 계획과 실행 기록
선택한 파일의 로컬 참조·크기·해시, 승인 참조, 설정, 업로드 시도와 재개 상태를 기록합니다. 보호된 상태에는 업로드 재개 주소도 포함됩니다. 비밀을 제외한 결과 보고서·화면 증빙을 운영자가 별도로 보관할 수 있습니다. 이 보고서에도 API 데이터나 계정 정보가 포함될 수 있습니다.

저장 위치와 보호 범위

인증 프로필과 재개 상태는 운영자 컴퓨터의 별도 상태 폴더에 저장됩니다. Linux 파일 권한으로 폴더는 소유자만 접근하고 파일은 소유자만 읽고 쓰도록 검사합니다. 앱 자체의 저장 암호화는 구현되어 있지 않습니다. 컴퓨터에 접근할 수 있는 소유자·관리자와 해당 컴퓨터에서 승인받아 실행되는 도구는 데이터에 접근할 수 있습니다.

원본 제작물, 계획, 승인 자료와 별도 결과 기록은 상태 폴더와 구분해 로컬 제작 폴더에 보관합니다. 외부 보고서·화면 사본은 연결 해제 명령의 자동 정리 대상이 아닙니다. 이 공개 사이트와 공개 Git 저장소에는 이러한 자료나 인증 정보를 게시하지 않습니다.

전송·공유와 이용 제한

선택한 제작물과 설정은 승인한 동작을 수행하기 위해 Google/YouTube로 전송됩니다. 현재 실행기는 광고, 데이터 판매, 사용자 추적이나 범용 AI 모델 학습을 위한 전송 기능을 갖고 있지 않습니다. Google에서 받은 데이터는 위에 설명한 게시·복구·검증 용도로만 사용합니다. 별도의 AI 작업 환경에서 결과를 검토한다면 그 환경에도 표시한 정보가 전달될 수 있으므로 비밀·원본·불필요한 계정 정보를 제공하지 않아야 합니다.

이 정적 사이트에는 자체 분석 스크립트, 광고, 로그인 폼, 쿠키 또는 브라우저 저장소를 사용하는 코드가 없습니다. GitHub Pages의 호스팅 요청과 GitHub 문의는 GitHub에서 처리하며 GitHub 개인정보처리방침이 적용됩니다. 외부 링크를 열면 해당 서비스가 요청을 받습니다.

현재 보관 방식과 구현 한계

현재 도구에는 보관기간에 따른 자동 만료, 정기적인 권한 재확인 또는 모든 외부 기록을 찾아 지우는 기능이 없습니다. 상태 파일과 별도 기록은 명시적인 연결 해제 또는 운영자의 수동 정리 전까지 남습니다. 따라서 이 페이지는 정책상 요구되는 보관·갱신·삭제 기한이 자동으로 충족된다고 보장하지 않습니다.

YouTube 개발자 정책에는 저장 API 데이터의 갱신·삭제와 권한 철회·삭제 요청 처리 기한이 있습니다. 예를 들어 일반적인 저장 승인 데이터의 30일 이내 갱신 또는 삭제, 앱을 통한 철회·삭제 요청 후 7일 이내 처리가 요구되는 경우가 있습니다. 해당 기한과 외부 기록까지 포함한 처리 절차의 이행 검증은 심사 전 남은 과제입니다. 이를 자동 삭제 기능이 구현된 것으로 해석하지 마세요.

권한 철회와 삭제 방법

  1. Google 계정의 서드 파티 접근 권한 관리에서 Creator-Publishing-Desk의 접근을 철회할 수 있습니다. 이 조작만으로 로컬 파일이 삭제되지는 않습니다.
  2. 로컬 도구의 명시적 연결 해제 기능은 관련 프로필 범위를 확인하고 Google에 토큰 철회를 요청합니다. 철회가 확인된 경우 도구가 관리하는 해당 프로필과 업로드 시도 데이터를 지웁니다. 응답이 불확실하면 확인할 때까지 멈춥니다. 같은 Google Cloud 프로젝트의 다른 연결에도 영향이 있을 수 있어 범위 확인이 필요합니다.
  3. 운영자는 상태 폴더 밖에 둔 API 조회 결과·보고서·화면 사본과 별도 보관 사본을 확인해 관련 API 데이터를 수동으로 정리해야 합니다. Google에서 먼저 철회한 경우에도 이 정리가 필요합니다. 현재 이를 주기적으로 감지·자동 수행하는 작업은 없습니다.
  4. 원본 제작물, 원래 클라이언트 설정 파일, 계획·사람의 승인 기록은 연결 해제 명령이 삭제하지 않습니다. 그 안에 복사된 API 데이터가 있다면 구분해 정리해야 합니다. YouTube에 저장된 영상도 삭제되지 않으며, 원격 영상을 삭제하려면 YouTube Studio 등에서 별도로 처리해야 합니다.

연결 해제·삭제 기능은 모의 응답으로 검증했으며 실제 권한 철회·삭제 시험은 수행하지 않았습니다.

문의와 삭제 요청

공개 GitHub 문의 창구에서 Creator-Publishing-Desk 관련 개인정보 문의·불만 또는 로컬 데이터 삭제 도움을 요청할 수 있습니다. 이슈에 토큰, 클라이언트 비밀, 영상 파일, 비공개 영상 링크, 개인 이메일 등을 게시하지 마세요. 먼저 비밀 없는 요청으로 범위를 협의해 주세요. 별도 비공개 접수 창구나 자동 삭제 접수 시스템은 현재 제공하지 않습니다.
